# 하트는 학생 신원이 아니라 브라우저 기준으로 중복 방지한다

학생 계정이나 개인별 참여 코드의 발급·분실 관리를 추가하지 않고 응원 반응을 제공하기 위해, 하트 참여자는 학급별 무작위 브라우저 식별자의 해시로 구분한다. 관찰 자료와 교사 피드백 본문은 교사 소유 Google Sheets에 유지하되, 하트 관계는 중앙 D1에 보관하여 `(class_id, observation_id, voter_key)` 고유 제약으로 반복·동시 요청의 중복을 막는다. 사람당 한 번이라는 보장보다 개인정보와 운영 부담을 늘리지 않는 구조를 선택했으며, 하트를 투표·평가 점수로 사용하지 않는다.

## 결과

- 쿠키 삭제·만료, 시크릿 모드, 다른 기기에서는 중복 참여가 가능하고 공유 브라우저는 한 참여자로 취급한다.
- 이름·번호·IP·기기 지문을 식별자와 연결하지 않으므로, 나중에 학생 계정 기준으로 바꾸더라도 기존 하트를 실제 학생에게 소급 귀속할 수 없다.
- Sheets와 D1 사이에는 원자적 트랜잭션이 없다. 기록 재확인·보상 삭제·멱등 삭제 재시도를 사용하되, 프로세스 강제 종료나 보상 삭제 실패까지 자동 복구한다고 보장하지 않는다.

구체적인 보관·삭제 및 배포 절차는 [README](../../README.md#교사-피드백과-하트)를 따른다.
