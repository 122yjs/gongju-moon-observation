## 제보와 판정

1. Drive에는 사진이 있는데 갤러리에 추가되지 않는 제보.
2. 약 20개 이후 갤러리와 Drive 모두에 추가되지 않는 제보.

두 제보를 동일 원인으로 단정하지 않는다. 코드에는 20개 누적 제출 제한이 없고, 실제 조회 함수를 합성 사진 50개로 실행했을 때 최신순 12개 페이지를 이어 읽어 50개 모두 중복 없이 조회했다. 기존 제한은 브라우저별 10분 3회, 학급별 1시간 100회 제출 시도이며, 별도로 갤러리/요약 시트의 원본 조회 상한 2,000행이 있다. 이번 수정은 이 한도들을 변경하지 않는다.

## 재현한 결함과 수정

### 갤러리가 필수적이지 않은 캐시 쓰기에 의존

기존 코드는 시트를 성공적으로 읽어도 `seedImageTickets` 쓰기가 실패하면 학생/교사 갤러리 전체가 500 오류를 반환했다. 이미지 조회도 임시정보/행 색인 장애에 막혔다. 합성 장애 주입으로 재현했다.

수정 후 임시정보 쓰기와 행 색인 복구는 부가 작업으로 취급한다. 실제 사진은 인증된 학급의 시트와 Drive 폴더 확인을 거친다. 비공개 사진과 없는 사진은 학생에게 여전히 404이다. 인증 실패나 Google 원본 조회 실패를 성공으로 바꾸지 않는다. D1 전체 장애까지 해결하는 것은 아니다.

### 중단된 저장 잠금과 명확한 거부 응답 처리

모든 Google 쓰기 예외를 `uncertain`으로 바꾸던 처리 중, 단일 append의 명확한 거부 응답만 안전하게 분리했다. 통신 단절·5xx·다단계 쓰기는 여전히 보수적으로 잠금을 보존한다. 잠금 삽입/확인 단계에서 실패하고 Google 쓰기가 시작되지 않았다면 해당 시도의 owner token만 정리한다.

교사의 시트 연결 점검에는 오래된 단일 append의 **실제 저장 완료 확인**을 추가했다. 5분 이상 경과하면서 관찰 ID와 내용 버전까지 일치해야 한다. 확인된 기록의 기존 제출 영수증을 학급·요청 ID로 한정해 보정한다. 누락 행, 버전 불일치, 다른 학급, 최근 요청, 다단계 변경, 영수증 보정 실패는 잠금을 유지한다. 시간만으로 해제하지 않는다.

### 모바일 연결 종료 시 처리 수명

변경 API의 동일한 처리 Promise를 `ctx.waitUntil`에도 등록하되, 응답은 계속 처리가 끝날 때까지 기다린다. 조기 성공 응답이나 이중 전송은 없다. 연결 종료 후 처리 중단 위험을 줄이는 장치이며, Cloudflare의 종료 후 최대 30초 한계가 있으므로 영구 작업 큐나 무조건 완료 보장은 아니다.

## 운영 적용 전후 확인

배포와 기존 데이터 복구는 별도 단계다. 배포 후 제보 학급을 식별하여 갤러리 응답과 교사 시트의 관찰 ID/요청 ID/사진 파일 ID를 대조해야 한다. 원본 시트에 저장된 기록은 점검 경로로 확인 복구하고, Drive만 저장된 기록은 메타데이터 대조 없이 새 행을 만들거나 원본을 지우지 않는다. Drive에도 없는 실패 건은 실제 미저장 여부를 확인한 뒤 재제출 안내가 필요하다.

정상 경로의 Google 쓰기 횟수나 학생 개인정보 보관 위치는 변경하지 않았다. 캐시 장애 시 원본 시트 조회로 우회하므로 일시적으로 Google 읽기가 늘 수 있다.
